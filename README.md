# Yifan Wang — Portfolio

Desktop portfolio for Yifan Wang. The page is a Mac-style desktop that fills the window. Memory, portfolio, and music folders open one window each. The about card switches between About me, What I do, and Beyond Design.

## Run

```bash
npm install
npm run dev
```

The dev server is at [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Sola videos

Drop these four files into `public/videos/` before pushing to GitHub or deploying on Vercel. Keep the spaces in the filenames:

- `solar video1.mp4`
- `solar video2.mp4`
- `solar video3.mp4`
- `solar video4.mp4`

They fill the video boxes, play on a loop, and stay muted with no controls. The boxes stay blank until the files are in that folder.
